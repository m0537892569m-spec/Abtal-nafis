أبطال نافس - نسخة محدثة
الملفات: index.html للمسابقة، teacher.html للمعلم، config.js للربط، supabase_setup.sql لإنشاء الجدول والسياسات.
1- ارفع محتويات ZIP إلى Netlify (يمكن رفع ZIP مباشرة).
2- في Supabase > SQL Editor نفذ supabase_setup.sql إذا لم يكن الجدول موجودًا.
3- أنشئ مستخدم المعلم في Authentication > Users.
4- افتح teacher.html وسجّل الدخول.
5- الأسئلة المستخرجة من صورة/PDF/Word تتطلب مراجعة وتصحيحًا، ثم تُحفظ غير معتمدة حتى تنشرها يدويًا.
مهم: سياسات SQL تسمح لأي مستخدم authenticated بالكتابة؛ استخدم مشروعًا بحسابات معلمين موثوقة فقط، وأوقف التسجيل العام.
مهم: قراءة PDF الممسوح ضوئيًا غير مدعومة تلقائيًا؛ استخدم صورة واضحة للصفحة.
المرفقات الاختيارية تتطلب إنشاء bucket باسم nafis-attachments وسياسات رفع مناسبة؛ يمكن حفظ الأسئلة بدون مرفقات.

تحديث قراءة الصور: يتم استخراج النص محليًا عبر Tesseract.js (يتطلب إنترنت أول مرة)، ويجب مراجعة الأسئلة والخيارات والإجابات. المهارة لا تُستخرج تلقائيًا بل يدخلها المعلم يدويًا.
